# ベイブレードX 物理知識 要点

回転体力学の観点から、ベイブレードXの挙動・パーツ性能を根拠づけるための要点集。
主張には信頼度を付す：**【物理法則】**（教科書・例外なし）／**【高信頼】**（査読論文・一次データ）／**【中信頼】**（単一ソース・要検証）／**【推測】**（物理からの類推・未検証）。

優先順位は **物理法則 > 実験データ > コミュニティ評価**。物理に反する主張は採らない。
大会データはこの序列の外にある。**大会記録が示すのは「何を使ったか」だけで、「なぜ勝ったか」ではない。**
パーツ・カスタムの評価は物理特性で論旨を立て切り、大会実例はその補強に置く。

## 1. 回転体の基礎

### 慣性モーメント I 【物理法則】
```
I = Σ(m × r²)   m=質量, r=回転軸からの距離
```
- **rが2倍ならIは4倍（二乗則）。** 効くのは「重さ」より「置き場所」。
- 外周に質量集中 → 高I → 高スタミナ・高耐衝撃（例：ウィザードロッドのウィング型）。
- 中心寄り → 低I → 高機動・弾きの鋭さ（コンパクトアタック型）。
- 目安：外周4cm型 ∝ 4²=16、外周2cm型 ∝ 2²=4 → **慣性モーメント比 約4倍**。

### 角運動量 L 【物理法則】
```
L = I × ω   ω=角速度
```
- 外力がなければ保存（角運動量保存則）。**シュート直後はωが最大＝Lも最大。**
- L大 → 強いジャイロ効果 → 傾いても自己修正する復元力 → スタミナ型が「揺れない」理由。
- 衝突時、アタック型（低I）は自分のLを大きく失い、スタミナ型（高I）は移転Lを吸収して回り続ける。**「重いスタミナ型がアタック型を消耗させる」の正体。**

### 遠心力 F_c 【物理法則】
```
F_c = m × ω² × r   （ωが2倍 → F_cは4倍）
```
- 高回転ほど強大。Rush系ビットでは高回転時にビット外周がスタジアム面へ押し付けられ、**Xライン乗り上げが起きやすい**。低回転に落ちるとセンター安定挙動へ移行。

### 摩擦力 f 【物理法則】
```
f = μ × N   μ=摩擦係数, N=垂直抗力
```
| ビット | 接地 | 摩擦 | スタミナ | 制動/アタック |
|---|---|---|---|---|
| Taper（点） | 極小 | 最小 | 最高 | 低 |
| Ball（球） | 小〜中 | 小 | 高 | 低〜中 |
| Flat（面） | 大 | 大 | 低 | 高 |
| Rush（複合） | 速度依存 | 可変 | 可変 | 条件依存 |
- Taperは μ低 × N小 で摩擦損失最小＝回転保持率が最高。円錐の復元力でセンター維持し壁激突ロスも減る。

## 2. 歳差運動と章動（「倒れない」「終盤に暴れる」の正体）

### なぜ倒れないか 【高信頼】
高速回転体の各部に働く遠心力が「軸を四方から引く紐」として対称に作用し、重力による傾きを歳差運動として逃がしながら軸を立て続ける（森下 2015）。数学的には角運動量保存則と等価。力で語るならコリオリ力による対抗モーメントの釣り合いとして説明できる。

### 歳差速度の反比例則 【物理法則】
```
Ω_p = τ / L = (M × g × H) / (I × ω)
```
- **歳差速度はスピン角速度に反比例する。**
  - ω大 → Ω_p小 → 歳差ゆっくり → 軸が安定
  - ω小 → Ω_p大 → 歳差が速く → 「激しい揺れ」へ
- 適用：シュート直後（ω最大）が最も安定。回転が落ちるほど軌道が不安定化。**終盤の「暴れ」は偶然ではなく反比例則の帰結。**
- スタミナ型が長く戦える本質：高I → ωが落ちにくい → Ω_pの加速が遅い → **安定が長続きする**（「長く回る」だけでなく「長く安定を保つ」）。

### 章動の減衰 【高信頼】
現実のコマは歳差に加え、軸が上下に微振動する「章動」を伴う（＝ふらつき感の正体）。接地摩擦が章動エネルギーを熱に変え、振幅が減衰して定常歳差に収束する。
- Taper（低摩擦）→ 章動が消えにくい → 打ち直し後のふらつきが長い
- Flat系（高摩擦）→ 章動が早く消える → 接地後すぐ安定
- **「シュート直後に落ち着くまでの時間差」はビット選択の隠れたトレードオフ。**

## 3. シュート力学

### 初期角速度の最大化 【物理法則 / 高信頼】
```
ω_initial = v_string / r_gear
```
- 目的は ω の最大化。
- **脱力シュートの根拠**：筋の力-速度特性（ヒルの曲線）により、力みすぎると収縮速度が落ち v_string が下がる。脱力で最大速度収縮 → ω最大。「力を抜くと速い」は感覚ではなく筋収縮の物理。
- 関節スナップ：肩→肘→手首→指の近位-遠位連鎖で角速度が加算（鞭の原理）。各関節の最大速度がこの順で達することは複数の査読研究で確認【高信頼】。

### シュート角度 【中信頼】
- 水平（θ≈0°）：Xライン乗りやすい → エクストリームダッシュ発動↑
- 斜め下打ち：相手ラチェットへのコンタクト角が生まれバースト狙い向き
- 高打ち（上向き）：着地衝撃大でジャイロ効果が低い状態から始まる → 基本非推奨

## 4. 衝突・バースト力学

### 衝突 【物理法則 / 高信頼】
実戦は不完全弾性衝突（一部がエネルギー損失）。I_defender ≫ I_attacker のとき、守る側の損失率は小さく攻める側が大きく消耗する。
- **コンタクト角が90°（正面）に近いほどエネルギー散逸が最小**（EJP 2007）。シャークエッジ系「下向き刃」の設計意図と整合。

### バースト 【物理法則 / 中信頼】
```
衝突の衝撃力 × コンタクト角度 ≥ ラチェットのバースト閾値
```
- 斜め上から → ラチェット解放トルク増 → バーストしやすい
- 正面水平 → 力が分散 → バーストしにくい
- 下向き刃 → ビット方向への力 → バーストより弾き

### ラチェット接触の局所性 【高信頼・確定】
ラチェットの接触は局所的。効くのは「枚数」ではなく**当たった1枚の形**（6枚/5枚の差はここ）。高さ選択（60系=低重心 / 80系=高重心）はビット選択と切り離せない。例：1-70は攻撃型ビットで真価。

## 5. スタジアム力学

### Xライン（エクストリームレール）【中信頼】
水平速度成分がレール乗り上げ閾値を超え、かつビット外周接触（遠心力依存）が成立すると乗り上げる。底面ランナーがXラインをトレースし摩擦方向が変化、周回速度が増す＝エクストリームダッシュ。

### 傾斜スタジアム 【中信頼〜推測】
```
Fg_parallel = m × g × sin(θ)   （傾斜方向への加速力）
```
- 重力の接線成分が遠心力の向きと重なる側でベイが加速 →「左を取る」戦術の物理的根拠。
- スピンするコマを傾斜面に置くと軸が**坂の上方向**に向いて安定（重力分力が歳差トルクになる）。傾斜スタジアムのスタミナ型が高い側に集まりやすいのは「力学的傾向」。ただしθ・I・ωで変わるため「必ず」ではなく「傾向」として扱う。

## 6. パーツ評価チェック（物理視点）

- **ブレード**：重量分布（外周/中心）、推定I（大/中/小）、コンタクト位置・角度、全体重量、タイプ整合。
- **ラチェット**：高さ（60/80系）、刃の形、バースト耐性、相性ブレードとの重心整合。
- **ビット**：接地形状（点/球/面/複合）、摩擦特性、回転速度依存挙動。
- **整合性**：3パーツの設計思想が同方向か。同方向＝強カスタム、バラバラ＝長所が打ち消し合う。
